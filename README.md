# tools.potentiate.bio

The home page for open tools from [potentiate.bio](https://potentiate.bio).

Each tool lives in its own repository with GitHub Pages turned on, and is served automatically
at `tools.potentiate.bio/<repository-name>/` — for example
[tools.potentiate.bio/thoughtful-outreach](https://tools.potentiate.bio/thoughtful-outreach/).

To list a new tool, add a card to `index.html` pointing at `/<repository-name>/`.
